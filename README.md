# Telegram-бот для проведения розыгрышей (Raffle Bot)

Асинхронный Telegram-бот для автоматизации регистрации пользователей, проверки условий (подписка на канал) и подведения итогов розыгрышей. Бот включает удобную step-by-step админ-панель, защиту от фрода и автоматическую генерацию персональных изображений для победителей.

## 🛠 Технологический стек
- **Язык:** Python 3.11
- **Фреймворк:** aiogram 3.x (с использованием Redis для хранения состояний FSM)
- **База данных:** MySQL 8.0 (драйвер `aiomysql`)
- **ORM & Миграции:** SQLAlchemy 2.0 (async) + Alembic
- **Планировщик:** APScheduler (асинхронные cron-задачи)
- **Медиа & Экспорт:** Pillow (генерация изображений), openpyxl (выгрузка в Excel)
- **Инфраструктура:** Docker & Docker Compose

## ✨ Основной функционал

**Для пользователей:**
- Регистрация в активном розыгрыше (ФИО, ВУЗ).
- Автоматическая проверка подписки на спонсорский Telegram-канал.
- Защита от дублей (один аккаунт — одна заявка на конкретный розыгрыш).
- Получение персональной картинки-поздравления в случае победы.

**Для администраторов (доступ по белому списку ID):**
- **Создание розыгрыша:** пошаговый диалог (кол-во победителей, дедлайн, канал для подписки).
- **Модерация:** бан/разбан нарушителей по Telegram ID.
- **Экспорт:** мгновенная выгрузка базы участников активного розыгрыша в `.xlsx`.
- **Итоги:** досрочное завершение розыгрыша с мгновенным определением победителей (рандомайзер) и рассылкой результатов.
- **Антифрод-система:** автоматические алерты в ЛС админам при всплеске регистраций (>5 заявок за 1 минуту).

## 🚀 Установка и запуск (Docker)

### 1. Подготовка окружения
Клонируйте репозиторий и создайте файл `.env` в корне проекта:
```bash
cp .env.example .env

```

Пример содержимого `.env`:

```env
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrSTUvwxYZ
DATABASE_URL=mysql+aiomysql://root:password@mysql:3306/raffle_db
REDIS_URL=redis://redis:6379/0
ADMIN_IDS=123456789,987654321

```

*Примечание: в `DATABASE_URL` и `REDIS_URL` вместо localhost используются имена сервисов из docker-compose.*

### 2. Запуск контейнеров

Запустите всю инфраструктуру (Бот, MySQL, Redis) одной командой:

```bash
docker compose up -d --build

```

### 3. Применение миграций БД

После того как база данных инициализируется (через 10-15 секунд после запуска), создайте структуру таблиц:

```bash
docker compose exec bot alembic upgrade head

```

### 4. Проверка логов

```bash
docker compose logs -f bot

```

## 🎨 Интеграция дизайна (Для Frontend / Дизайнера)

Модуль генерации изображений находится в `bot/services/image_gen.py`.
Ассеты хранятся в папке `bot/assets/`.

**Что нужно сделать, чтобы внедрить реальный дизайн:**

1. Заменить файлы заглушек в `bot/assets/` на реальные:
* `font.ttf` — фирменный шрифт.
* `summary_bg.png` — фон для таблицы всех победителей (отправляется админам).
* `personal_bg.png` — фон для персональной карточки (отправляется в ЛС победителю).


2. В файле `image_gen.py` скорректировать координаты `(x, y)`, цвет `fill` и размер шрифта в методах `_draw_summary_image` и `_draw_personal_image` согласно макету из Figma.

## 🗂 Структура проекта

```text
├── alembic/                # Конфигурации миграций
├── bot/                    # Исходный код бота
│   ├── assets/             # Шрифты и фоны для генерации картинок
│   ├── database/           # Модели SQLAlchemy (models.py) и подключение (engine.py)
│   ├── filters/            # Кастомные фильтры (is_admin.py)
│   ├── handlers/           # Обработчики сообщений (admin.py, user.py)
│   ├── services/           # Бизнес-логика (raffle.py, image_gen.py)
│   ├── states/             # Состояния FSM (admin.py, user.py)
│   ├── config.py           # Загрузка переменных окружения
│   └── scheduler.py        # Задачи APScheduler (проверка дедлайнов)
├── migrations/             # Версии миграций Alembic
├── .dockerignore           # Исключения для сборки образа
├── docker-compose.yml      # Конфигурация сервисов (bot, mysql, redis)
├── Dockerfile              # Инструкция сборки образа бота
├── main.py                 # Точка входа
└── requirements.txt        # Зависимости Python

```
